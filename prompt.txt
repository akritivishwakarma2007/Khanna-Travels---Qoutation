Create a modern, professional **Insurance Quotation Comparison Web App** for travel insurance. The uploaded reference image shows the pricing tables that should be used as the initial quotation/rate data.

 ### Core Purpose

 The website should allow an insurance agent/user to enter a customer's travel details and automatically compare insurance quotations from multiple insurance companies based on the available rate tables.

 ### Input Form

 Create a clean, step-by-step or single-page form with:

 **Customer Details**

 - Customer name
- Age
- Number of travelers

 **Trip Details**

 - Departure date
- Return/arrival date
- Destination country
- Departure country
- Trip duration — automatically calculate from dates
- Coverage requirement / Sum insured:
  - USD 50,000
  - USD 250,000
  - USD 500,000
- USA & Canada coverage:
  - Excluding USA & Canada
  - Including USA & Canada

 The system must automatically calculate the number of travel days and identify the correct **Days Slab** from the quotation data:

 - 1–4
- 5–6
- 7–8
- 9–12
- 13–14
- 15–21
- 22–28
- 29–35
- 36–47
- 48–60
- 61–75
- 76–90
- 91–105
- 106–120
- 121–140
- 141–160
- 161–180

 ### Quotation Logic

 Use the uploaded image/table as the initial pricing database.

 The pricing structure is:

 **Plan:** Value Pro\
 **Coverage:** USD 50,000 / USD 250,000 / USD 500,000\
 **Region:** Including USA & Canada / Excluding USA & Canada\
 **Age bands:**

 - 0–40 years
- 41–60 years
- 61–70 years
- 71–80 years
- 81–85 years

 When the user enters an age, travel duration, coverage amount, and USA/Canada preference, automatically find the matching price from the corresponding quotation table.

 For example:

 `Age → Age Band`\
 `Travel Dates → Number of Days → Days Slab`\
 `Coverage Amount → Correct Coverage Table`\
 `USA/Canada Selection → Including/Excluding Table`\
 `All values → Matching quotation price`

 ### Data Architecture

 Do not hardcode the comparison logic directly into the UI.

 Create a structured pricing database such as:

```
Insurance Company
Plan
Coverage Amount
Region
Age From
Age To
Days From
Days To
Premium
Currency
```

 The calculation engine should query this data dynamically.

 Example:

```
Age = 45
Trip Duration = 18 days
Coverage = USD 250,000
Region = Including USA & Canada

Age Band → 41–60
Days Slab → 15–21

Find:
Coverage = 250,000
Region = Including
Age Band = 41–60
Days Slab = 15–21

Return matching premium
```

 ### Important Validation

 Handle:

 - Missing dates
- Return date before departure date
- Invalid age
- Age outside available range
- Trip duration above 180 days
- Missing quotation/rate
- Unsupported destination
- No matching insurance company

 Show clear user-friendly error messages.

 ### Important Product Requirement

 Design the application so that **multiple insurance companies can be added later**. The current uploaded Value Pro tables should be treated as the initial rate data, but the architecture must support unlimited companies and plans.

 The final experience should feel like a real-world **insurance broker/agent quotation comparison platform**, with a fast workflow:

 **Enter customer details → Enter travel dates → Automatically calculate days → Select coverage → Automatically match rate tables → Compare insurance companies → Select best quotation → Generate/save/share quotation.**

 Use the uploaded image as the visual and data reference for the initial **Value Pro** rate tables.
